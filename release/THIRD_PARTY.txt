Jura - The Jura Project Authors, SIL Open Font License 1.1 (500, 600, 700, Latin, from Fontsource

PawnIO module AMDFamily17.bin 0.2.11 - namazso and contributors, LGPL-2.1 (components\PawnIO,
unchanged signed build from https://github.com/namazso/PawnIO.Modules/releases/tag/0.2.11, source
in the same repository; licences\PawnIO.Modules-LGPL-2.1.txt). Used only when you have installed
PawnIO yourself from pawnio.eu; Frame Lab does not include or install the PawnIO driver.

HitchRecorder's script timing is original code. Ideas and data layouts it relies on:
  - redscript-dap by jekky (MIT): the game binds each script function to its source file at load,
    which is how a function is traced back to a .reds file.
  - LuaJIT (Mike Pall, MIT) as built into Cyber Engine Tweaks (yamashi and contributors, MIT): the
    VM's entry for protected calls and its function/prototype layout, read to time CET mods.
  Nothing of these projects is copied into HitchRecorder.

Radeon cards are read through AMD's own amdadlx64.dll (installed with the AMD driver). The layout of
its interfaces follows the AMD ADLX SDK headers (AMD, MIT licence); nothing of the SDK is included.

WolvenKit console 9.1.0 (Frame Lab 2.5E only) - the WolvenKit project and contributors, GPL-3.0
(components\WolvenKit: the official release WolvenKit.Console-9.1.0.zip, unpacked and unchanged; its
licence and where its source is are in LICENSE.txt and SOURCE.txt in that folder). Frame Lab reads the
game's file names from its path list and starts its console as a separate program; nothing of it is
built into Frame Lab.

The game's own options are read through Cyber Engine Tweaks' GameOptions (yamashi and contributors,
MIT) from Frame Lab's small CET mod (FrameLabMarkers\cet); in Frame Lab 2.5E the Game options page and
Optimise also set them, from FrameLabOptions.
